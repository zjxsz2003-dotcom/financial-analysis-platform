## 一、一条主线（面试讲解就用这条）

```
数据导入  →  ① 经营诊断  →  ② 业财归因  →  ③ 财务风险  →  ④ 预算与战略  →  ⑤ 分析报告
           「现在怎么样」  「为什么会这样」 「会出什么问题」 「离目标多远、怎么补」   「输出成果」
```

| 步骤 | 页面 | 回答的问题 | 核心方法 |
|---|---|---|---|
| — | 数据导入 | 数据可靠吗 | 三格式解析 · 勾稽校验 · 质量评级 |
| ① | 经营诊断 | **现在怎么样** | 五维体检 · 杜邦五因素连环替代 · 行业对标 |
| ② | 业财归因 | **为什么会这样** | 利润含金量 · 毛利率两因素分解 · 成本弹性 · CCC · 业务档案 |
| ③ | 财务风险 | **会出什么问题** | 六维评分卡 · Altman Z · 流动性阶梯 · 压力测试 · 传导链 |
| ④ | 预算与战略 | **离目标多远、怎么补** | 利润桥 · 滚动预测 · 目标进度 · What-if · 盈亏平衡 |
| ⑤ | 分析报告 | **给管理层什么** | 一键生成 · Markdown / HTML / PDF |

每页顶部都有「核心结论」文字区（数据动态生成），下面是明细——**先讲结论，再展开证据**。

讲解示例（立讯精密 2025）：
> ① 诊断：ROE 19.26%，但五年 −4.98pp，主因 EBIT 利润率贡献 −9.98pp →
> ② 归因：毛利率 +1.16pp 靠结构升级（通讯板块 18.4% 占比提升）；汽车 +185% 实为收购莱尼并表；
> 经营现金流 −36% 与净利 +24% 背离 →
> ③ 风险：综合 44 分（中低），但流动性 90 分是最大敞口，现金/短债 0.65 →
> ④ 决策：收入超预算 6.7%，但费用效应 −81.7 亿；盈亏平衡 1624 亿、安全边际 51% →
> ⑤ 输出：一键生成报告

## 二、核心方法（区别于普通看板的关键）

| 分析 | 做法 |
|---|---|
| ROE 归因 | **五因素杜邦**（税负 × 利息负担 × EBIT利润率 × 周转率 × 权益乘数）+ 连环替代法，逐年量化 pp |
| 毛利率归因 | **结构效应 + 毛利率效应 + 交叉效应**，三项之和精确等于总变动，无残差 |
| 毛利偏差 | 分板块拆「规模效应（卖得少）」vs「毛利率效应（卖得便宜）」 |
| 利润偏差 | **净利润预算→实际利润桥**：收入规模 / 毛利率 / 期间费用 / 税项四段闭环 |
| 费用偏差 | 拆「规模效应（合理增长）」vs「费率效应（管控成效）」 |
| 盈利质量 | 六维评分 + 净利润→自由现金流桥（+折旧摊销 → ±营运资本 → −资本开支） |
| 营运资本 | DSO + DIO − DPO = CCC，量化「每缩短 10 天释放多少亿」 |
| 成本性态 | 本量利：边际贡献率、固定成本、盈亏平衡收入、安全边际、DOL/DFL/DTL |
| 风险量化 | 六维评分卡（含趋势惩罚）+ Altman Z/Z′ + 五套压力测试 + 传导链 |
| 预算预测 | 季节性外推 → 达成缺口 → 反推剩余期间需提速百分比 |

## 三、换公司还能用吗（泛化性）

- **零硬编码**：全系统无公司名 / 行业名 / 板块名
- **预算自动生成**：上一期实际 × 历史增速中位数（不用当期数据，无前视偏差），可编辑
- **战略目标自动生成**：历史最优值 + 行业基准推导，可编辑
- **行业基准可切换**：6 套预设 + 逐项自定义（来源已标注，见页面顶部）
- **缺数据优雅降级**：无分部 → 跳过板块分析；无现金流表 → 跳过质量分析；首页明示完备度
- **输入格式宽容**：CSMAR 标准 / 简版「首列年份」/ 简版「首列科目」，元·万元·亿元自动识别
- **业务档案按股票代码匹配**：匹配不到则完全不显示公司特定内容，不会串台

## 六、部署为永久链接（Streamlit Cloud）

代码已推送到 GitHub（`zjxsz2003-dotcom/financial-analysis-platform`，分支 `main`）。

按以下步骤拿到永久链接 **https://finance-v2.streamlit.app**：

1. 打开 https://share.streamlit.io → **New app**
2. 填写：
   - Repository：`zjxsz2003-dotcom/financial-analysis-platform`
   - Branch：`main`
   - **Main file path：`V2_专业版/app.py`**（⚠ 别留空，否则会部署到根目录的旧版）
3. 展开 **Advanced settings**，在 **App URL** 处填：`finance-v2`
   → 最终链接即 `https://finance-v2.streamlit.app`
   （若提示已被占用，改用 `finance-v2-zjx` 之类）
4. 点 Deploy，等 2–3 分钟即可访问，手机 / 其他设备都能打开

> 若已有一个旧版 app，也可在它的 Settings 里把 Main file path 改成
> `V2_专业版/app.py`、URL 改成 `finance-v2`，直接复用原有部署。

部署后若示例数据加载失败，检查仓库里 `V2_专业版/data/` 是否存在

## 八、已知边界

- EBIT 用「营业利润 + 财务费用」近似，含汇兑损益时有偏差
- 折旧摊销需现金流量表（间接法）；缺失时 EBITDA 退化为 EBIT
- 本量利把营业成本视为变动、期间费用视为固定，属简化假设
- 滚动预测为线性/季节性外推，未考虑在手订单与产能约束
- PDF 导出依赖系统中文字体，无字体时用 HTML 打印
- 业务档案来自公开报道（截至 2026-09），正式场合请用最新公告复核
